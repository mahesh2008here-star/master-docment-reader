## 🌟 Highlights & What's New

### 1. Droplert-Inspired AMOLED & Liquid Glass UI
- Ultra-modern iOS & Droplert-inspired aesthetics with frosted liquid-glass dock, blurred floating panels, and tactile pill selectors.
- True **AMOLED pitch black** dark mode (`#000000` base) alongside crisp warm light paper mode.
- Interactive color accent engine: customizable with 7 curated presets (Amber, Emerald, Violet, Blue, Coral, Lime, Slate) and a live Hex Color Picker.

### 2. High-Performance Universal Document Engine
- Genuine offline rendering for **PDF**, **DOCX**, **XLSX**, **PPTX**, and **Markdown** (`.md`).
- Proprietary page turning animations (horizontal slide, smooth fade, and 3D page flip).
- Dual zoom architecture: pinch-to-zoom, double-tap zoom, fit width, and fit height.
- Reading tools: dual highlighters (Amber, Emerald, Cyan, Pink), sticky annotation notes, search in document, and reading progress indicators.

### 3. Encrypted Private Document Vault (File Locker)
- Dedicated 4-digit PIN authentication with lockout protection and automatic 5-minute inactivity lock.
- Zero-cloud, local client-side encrypted vault for sensitive documents, contracts, and financial statements.
- Direct quick-import and export capabilities.

### 4. Comprehensive Offline Document Toolkit
- **PDF Page Merger & Splitter**: Combine multiple PDFs into a single document or split by page range.
- **Image-to-PDF Studio**: Select local photos or camera scans and compile into a multi-page PDF document.
- **Text & Metadata Inspector**: Extract text and metadata from files without external APIs.
- **Document Watermark & Stamping Engine**: Add custom diagonal or header watermarks before exporting.

### 5. Native Android & Modern Web Architecture
- **Web App**: Built with React 19, TypeScript, Tailwind CSS, Lucide icons, and Motion animations.
- **Native Android**: Kotlin 2.0, Jetpack Compose, Material 3, Android PdfRenderer, Room DB, and Android Storage Access Framework (`/android` directory).
- **100% Offline Guarantee**: No analytics, no ads, no trackers, and zero external network calls.
